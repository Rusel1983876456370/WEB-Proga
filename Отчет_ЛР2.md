## 2. Постановка задачи

В качестве основы используется проект **«АвтоДеталь — каталог автозапчастей»**, разработанный в лабораторной работе №1.

В первой лабораторной работе страница была статической: карточки автозапчастей были записаны непосредственно в HTML, а форма поиска не выполняла реальную фильтрацию.

Во второй лабораторной работе необходимо было добавить:

- динамический поиск автозапчастей;
- фильтрацию по категориям;
- сортировку по названию и цене;
- модальное окно для добавления новой детали;
- форму с клиентской валидацией;
- добавление новых карточек;
- удаление карточек;
- сохранение данных в `localStorage`;
- перерисовку страницы на основе объекта состояния `state`.

Вся логика написана на чистом JavaScript без использования jQuery и сторонних SPA-фреймворков.

## 5. Состояние приложения

Для хранения данных используется единый объект `state`:

```javascript
const state = {
  items: loadItems(),
  searchQuery: "",
  selectedCategory: "all",
  sortBy: "name-asc",
};
```

Свойства объекта:

| Свойство | Назначение |
|---|---|
| `items` | Массив автозапчастей |
| `searchQuery` | Текущий поисковый запрос |
| `selectedCategory` | Выбранная категория |
| `sortBy` | Выбранный режим сортировки |

После изменения состояния вызывается функция `render()`.

Принцип работы приложения:

```text
State → render() → DOM
```

То есть сначала изменяется состояние, после этого функция `render()` заново формирует отображаемую часть страницы.

{

## 7. Динамический поиск

Поиск реализован с помощью текстового поля:

```html
<input
  id="query"
  type="search"
  placeholder="Например, масляный фильтр"
>
```

Обработчик события `input` срабатывает при каждом изменении текста:

```javascript
$("#query").addEventListener("input", (event) => {
  state.searchQuery = event.target.value;
  render();
});
```

Поиск работает без перезагрузки страницы.

В функции `filteredItems()` запрос приводится к нижнему регистру:

```javascript
const query = state.searchQuery.trim().toLowerCase();
```

Поиск выполняется по следующим полям:

- названию детали;
- артикулу;
- описанию;
- названию категории.

Поэтому регистр букв при поиске значения не имеет.

## 8. Фильтрация по категории

Для фильтрации используется выпадающий список:

```html
<select id="category">
  <option value="all">Все категории</option>
</select>
```

Категории добавляются в список функцией `fillCategories()`.

Обработка выбора категории:

```javascript
$("#category").addEventListener("change", (event) => {
  state.selectedCategory = event.target.value;
  render();
});
```

В пункте `all` отображаются все детали. При выборе другой категории показываются только соответствующие элементы.

Проверка категории находится в функции `filteredItems()`:

```javascript
const matchesCategory =
  state.selectedCategory === "all" ||
  item.category === state.selectedCategory;
```

## 9. Сортировка

В приложении реализованы четыре варианта сортировки:

- название: А–Я;
- название: Я–А;
- цена: сначала дешевле;
- цена: сначала дороже.

HTML-элемент сортировки:

```html
<select id="sort">
  <option value="name-asc">Название: А–Я</option>
  <option value="name-desc">Название: Я–А</option>
  <option value="price-asc">Цена: сначала дешевле</option>
  <option value="price-desc">Цена: сначала дороже</option>
</select>
```

Обработчик изменения сортировки:

```javascript
$("#sort").addEventListener("change", (event) => {
  state.sortBy = event.target.value;
  render();
});
```

Для сохранения исходного массива используется его копия:

```javascript
return [...list].sort((a, b) => {
  if (state.sortBy === "price-asc") {
    return a.price - b.price;
  }

  if (state.sortBy === "price-desc") {
    return b.price - a.price;
  }

  return a.name.localeCompare(b.name, "ru");
});
```

Такой подход соответствует требованию иммутабельной сортировки.

## 10. Формирование карточек через DOM

Карточки не прописываются вручную в HTML. Они создаются функцией `makeCard(item)`.

Для создания элементов используются:

```javascript
document.createElement()
```

и:

```javascript
append()
```

Пример создания заголовка карточки:

```javascript
const title = document.createElement("h3");
title.textContent = item.name;
```

Для пользовательских данных используется `textContent`, а не `innerHTML`.

Это защищает страницу от вставки HTML-кода и потенциальных XSS-атак.

После создания всех элементов карточка добавляется в DOM:

```javascript
article.append(image, body);
```

## 11. Функция `render()`

Функция `render()` отвечает за полное обновление каталога:

```javascript
function render() {
  const items = filteredItems();

  cards.replaceChildren(...items.map(makeCard));

  emptyState.hidden = items.length > 0;
}
```

Функция выполняет следующие действия:

1. получает отфильтрованный и отсортированный список;
2. удаляет старые карточки;
3. создаёт новые карточки;
4. обновляет количество найденных элементов;
5. показывает сообщение, если ничего не найдено.

Таким образом, DOM всегда соответствует текущему объекту `state`.

## 12. Модальное окно

Для добавления детали используется модальное окно.

Открытие выполняется кнопкой:

```javascript
$("#add-item-button").addEventListener("click", openModal);
```

Функция открытия:

```javascript
function openModal() {
  modal.hidden = false;
  document.body.classList.add("modal-open");
  $("#item-name").focus();
}
```

Модальное окно закрывается:

1. кнопкой с крестиком;
2. кнопкой «Отмена»;
3. клавишей `Escape`;
4. нажатием на затемнённую подложку.

Закрытие по клавише `Escape`:

```javascript
document.addEventListener("keydown", (event) => {
  if (event.key === "Escape" && !modal.hidden) {
    closeModal();
  }
});
```

## 13. Форма добавления и валидация

В модальном окне находится форма добавления новой автозапчасти.

Поля формы:

- название;
- категория;
- цена;
- описание;
- артикул.

Для HTML5-валидации используются атрибуты:

```html
required
minlength="3"
maxlength="60"
min="1"
max="1000000"
pattern="[A-Za-zА-Яа-я0-9-]+"
```

Стандартная отправка формы отменяется:

```javascript
form.addEventListener("submit", (event) => {
  event.preventDefault();
});
```

Проверка выполняется через Constraint Validation API:

```javascript
if (input.validity.valueMissing) {
  message = "Заполните это поле.";
}
```

Также проверяются:

- минимальная длина текста;
- диапазон цены;
- соответствие артикулов заданному шаблону.

Сообщение об ошибке выводится под соответствующим полем через `textContent`.

## 14. Добавление новой детали

После успешной валидации данные формы считываются через `FormData`:

```javascript
const data = new FormData(form);
const category = data.get("category");
```

Затем создаётся новый объект:

```javascript
const newItem = {
  id: `USER-${Date.now()}`,
  name: data.get("name"),
  category,
  categoryLabel: categoryLabels[category],
  description: data.get("description"),
  article: data.get("article").toUpperCase(),
  parameter: "Добавлено пользователем",
  price: Number(data.get("price")),
  image: "filter.svg",
};
```

Объект добавляется в состояние:

```javascript
state.items.push(newItem);
```

После этого вызываются:

```javascript
persist();
render();
closeModal();
```

Новая деталь сразу появляется в каталоге и сохраняется после перезагрузки страницы.

## 15. Удаление карточки и Event Delegation

На каждой карточке создаётся кнопка «Удалить»:

```javascript
const deleteButton = document.createElement("button");
deleteButton.dataset.deleteId = item.id;
deleteButton.textContent = "Удалить";
```

Для удаления используется делегирование событий. Один обработчик устанавливается на общий контейнер карточек:

```javascript
cards.addEventListener("click", (event) => {
  const button = event.target.closest("[data-delete-id]");

  if (!button) {
    return;
  }

  const id = button.dataset.deleteId;

  state.items = state.items.filter(
    (item) => item.id !== id,
  );

  persist();
  render();
});
```

Метод `closest()` находит нажатую кнопку удаления.

После удаления:

1. элемент исключается из массива `state.items`;
2. обновлённый массив сохраняется в `localStorage`;
3. каталог перерисовывается.

## 16. Сохранение данных в `localStorage`

Для сохранения списка используется Web Storage API.

Функция сохранения:

```javascript
function persist() {
  localStorage.setItem(
    STORAGE_KEY,
    JSON.stringify(state.items),
  );
}
```

`localStorage` хранит только строки, поэтому массив преобразуется с помощью `JSON.stringify()`.

При загрузке страницы данные восстанавливаются:

```javascript
const saved = localStorage.getItem(STORAGE_KEY);

return saved
  ? JSON.parse(saved)
  : structuredClone(defaults);
```

`JSON.parse()` преобразует JSON-строку обратно в массив объектов.

Если хранилище пустое, приложение использует стандартные данные из `defaults`.
