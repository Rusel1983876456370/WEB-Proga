# АвтоДеталь — лабораторная работа №2

Интерактивный каталог автозапчастей на HTML, CSS и Vanilla JavaScript.

## Реализовано

- динамический поиск по названию, артикулу, категории и описанию;
- фильтрация по категориям с пунктом «Все категории»;
- иммутабельная сортировка по названию и цене;
- модальное окно добавления новой детали;
- Constraint Validation API (`required`, `minlength`, `min`, `max`, `pattern`) с сообщениями под полями;
- удаление карточек через делегирование событий на контейнере `.cards` и `closest()`;
- единый объект `state` и функция `render()` для State-Driven UI;
- сохранение массива в `localStorage` через `JSON.stringify()` / `JSON.parse()`;
- адаптивная верстка без сторонних библиотек.

## Запуск

Откройте `index.html` в браузере или запустите `python -m http.server 8000` в корне проекта.

## Структура

- `index.html` — разметка SPA и модального окна;
- `css/style.css` — стили ЛР1 и дополнения ЛР2;
- `js/app.js` — состояние, события, фильтрация, валидация и localStorage;
- `assets/images/` — SVG-иллюстрации деталей.
