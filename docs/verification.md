# Протокол проверки ЛР3

Дата: 30.10.2026. Среда: Linux, Python 3.12; Chromium 153, Playwright 1.64.1.

## API и БД

Команда из корня проекта: `python -m pytest -q`.
Результат: **44 passed**, без падений. Протокол сохранён в `api-tests.txt`.
Предупреждение библиотеки Starlette об httpx не мешает выполнению тестов.

Использована настоящая временная SQLite для каждого интеграционного теста,
а не mock-хранилище. Проверяются статусы и тела ответов, строки БД и SQL-ограничения.
Отдельный тест создаёт запись в одном процессе Python и читает её в другом.

## Браузер

13 проверенных сценариев, полные сообщения — `browser-tests.txt`:

1. Загрузка шести исходных деталей и категорий через API.
2. Поиск, фильтры и сортировка из ЛР2.
3. Валидация пустой формы и POST 201 из интерфейса.
4. Сохранение записи после перезапуска процесса Uvicorn.
5. GET по ID, PATCH цены/категории и перезагрузка страницы.
6. Ошибка повторного артикула в форме и закрытие окна Escape.
7. DELETE 204 из интерфейса; повторная загрузка подтверждает удаление.
8. Отображение ошибки сети и восстановление после повторного запроса.
9. Мобильный экран 390 px: нет горизонтальной прокрутки, форма доступна.
10. Локальный Swagger UI: метод раскрыт, выполнен GET с ответом 200.
11. Скриншот SELECT реальной SQLite с добавленной через POST записью.
12. Отдельный frontend :5500 получает каталог из backend :8000 через CORS.
13. Нет ошибок JavaScript; сетевой журнал подтверждает GET/POST/PATCH/DELETE.

Полный сценарий автоматизации: `scripts/check_browser.py`.
Playwright требуется только для повторной браузерной проверки, не для работы сайта.

в репозиторий владельца; реальный удалённый URL не предоставлен.
